# TUI plugins — ranked, classified TUI·Both (server side noted)

**Split focus.** The OpenCode TUI moves fully to Rust (OpenTUI + PsychoScript reducers); the server stays in TypeScript
for now. This file is the **TUI part**: every plugin from `TOP100.md` whose rewrite runs (at least in part) in the
terminal client, re-ranked by popularity within the TUI set.

**Counts.** 62 plugins are pure **TUI**; 11 more are **Both** (a server hook + a client surface) and appear here with
their TUI portion, and in `../server/TOP100.md` with their server portion. This list is therefore **73 rows**.
Popularity = stars (2026-11-19) then npm weekly downloads (week 2026-11-12→18), complexity as tiebreaker; figures are
unchanged from `../TOP100.md` (spot-check there).

**Side column:** `TUI` = runs only in the client · `Both` = split; the `(TUI:)` / `(server:)` prefixes in "What it
does" say which part is which. Archetypes and returns as in the merged table; host-fn names are the canonical names in
`./HOST-API.md`.

## How the 11 "Both" plugins split

| Plugin | TUI part | Server part |
|---|---|---|
| OpenCode | terminal UI: slots, prompt, file tree, status, keybinds | agent, model, tools, MCP, session lifecycle, compaction |
| mem0 | status slot + palette commands | memory tools + 16 slash cmds + capture-on-message + inject |
| openviking/Magpie | status slot (recall display) | recall/capture, model switching, auto-restart |
| plannotator | local browser annotation UI | plan-stream hook + apply edits back |
| oh-my-opencode-slim | status slot + keymap commands | background subagents, LSP/AST, tmux |
| opencode-mem | status/commands + local web UI | message capture/search/inject + vector index |
| opencode-supermemory | status slot + commands | hosted memory service (fetch/store/inject) |
| opencode-notifier | desktop toast + sound | session/permission lifecycle hooks + webhook |
| opencode-cursor | local proxy process | OAuth token + provider registration |
| opencode-ensemble | live dashboard + status | parallel subagents, worktrees, peer messages |
| opencode-llm-proxy | local gateway process | provider routing (server-side provider) |

The TUI-specific event surface, slots, and return shapes are in `./HOST-API.md`.
