# The 100 things a PsychoScript host must support — merged, ranked, deduplicated

**Decision.** Plugins are rewritten as PsychoScript reducers. Each event runs the plugin once with
`{ event, state }`; it returns `{ state, slots, commands }`. All side effects go through host functions
(sync / async / durable / namespaces); no timers, no ambient I/O, no npm in the plugin.

**This file.** The union of `research/plugins/opencode-plugins.md` (OpenCode community plugins) and
`research/plugins/tui-ecosystem-plugins.md` (terminal-app plugins and the OpenTUI ecosystem), merged into one
ranked list of 100. Ranking is **popularity first** (GitHub stars, then npm weekly downloads — both dated below),
with **complexity as the tiebreaker**. Read this table next to `HOST-API.md` (the host-function catalogue,
which is the main output).

**Popularity units and dates.** `★` = GitHub stargazers read **2026-11-19**. `dl/wk` = npm **last-week** downloads
for **2026-11-12 → 2026-11-18**. `★` after an OpenTUI monorepo package = star count from
`anomalyco/opentui-index` `packages/facts.json` (2026-11-19). `~` = catalog figure (awesome-market), approximate.

**Deduplicated** (see §"Deduplication" below): near-identical same-job plugins are merged into one row, the merged
names are listed in the name cell, and the canonical link is to the most-starred of the group. 20 rows are hosts or
full apps whose *plugin system* is being matched — they are marked `host` / `app` in the Archetype column, not
reducers.

## Archetypes

`A` auth/provider · `B` declarative registration (MCP/skill/provider) · `C` cross-session memory/context ·
`D` intercept/gate transform · `E` notification · `F` telemetry/usage · `G` multi-agent orchestration ·
`H` external tool bridge (fetch/exec) · `I` local server/proxy · `J` PTY/interactive shell ·
`K` TUI slot/status/sidebar UI · `L` scheduler · `M` git porcelain UI · `N` picker/fuzzy finder ·
`O` installer/registry · `P` editor transform · `Q` LSP/DAP client · `host`/`app` = a host or full app whose
plugin system (not the app) is being matched.

Returns use: `status` (=`slots.status`), `panel` (=`slots.panel`), `cmds` (=`commands`), `—` = nothing.
