# Server plugins — ranked, classified Server·Both (TUI side noted)

**Split focus.** The OpenCode server stays in TypeScript for now; this file is the **server part**: every plugin
whose rewrite runs (at least in part) on the agent/model side — tools, providers, auth, prompt/system transforms,
session-lifecycle hooks, MCP servers, compaction, telemetry, permissions, and multi-agent orchestration.

**Counts.** 27 plugins are pure **Server**; 11 are **Both** and appear here with their server portion (their TUI
portion is in `../tui/TOP100.md`). This list is therefore **38 rows**. Popularity figures unchanged from `../TOP100.md`.

**Side column:** `Server` = runs only on the server · `Both` = split; `(server:)` / `(TUI:)` prefixes in "What it
does" say which part is which. **Returns** here are the server-side reducer outputs — registered tools/slash
commands, context injections, permission decisions, tool results — *not* the TUI keymap/slots. Host-fn names are the
canonical names in `./HOST-API.md`.
