## Fixed

- **rust:** Code that no highlight paints now uses its text color, as in Core. This includes a Markdown fence with no language, an unknown language, or display math, and a held streaming fence. Before, the color of a theme's `default` scope, such as in the `opencode` theme, replaced the text color. See [Code, Markdown, and highlighting](/docs/bindings/rust/text). ([#2180](https://github.com/anomalyco/opentui/pull/2180))
