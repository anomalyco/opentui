date: 2026-08-23
summary: Double-click selects a word, triple-click selects a line, and selection gains configurable cell or boundary occupancy.
---

## Added

- **core:** Double-click selects a word and triple-click selects a line. A second press on the same cell within 500 ms selects a word, and a third selects a line. A single click still selects nothing. Dragging after a word click keeps the spaces between words. Shift+arrow after a multi-click extends by cell. `ASCIIFont` and tables stay cell-only. The click interval and word-character set are fixed. `SelectionBehavior` (`"cell" | "word" | "line"`) is accepted as an optional `behavior` argument by `CliRenderer.startSelection()`, `RenderContext.startSelection`, the `Selection` constructor, `TextBufferView.setLocalSelection()`, `TextBufferView.updateLocalSelection()`, `EditorView.setLocalSelection()` and `EditorView.updateLocalSelection()`. `Selection.behavior` and `LocalSelectionBounds.behavior` expose it. See [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1407](https://github.com/anomalyco/opentui/pull/1407))
- **core:** Selection occupancy is configurable with `SelectionOccupancy` (`"cell" | "boundary"`). `"cell"` includes both endpoint graphemes, as in Vim. `"boundary"` selects a half-open range between insertion points, as with a thin cursor. Set it with the `selectionOccupancy` option on `EditBufferOptions` and `EditBufferRenderable`. Read and write it with `TextBufferView.getSelectionOccupancy()`, `TextBufferView.setSelectionOccupancy()`, `EditorView.getSelectionOccupancy()` and `EditorView.setSelectionOccupancy()`. `EditorView` also adds `convertSelectionToCell()`, `gotoVisualLineEnd()`, `setSelectionColors()` and `setSelectionInclusive()`. See [Textarea](/docs/components/textarea) and [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1393](https://github.com/anomalyco/opentui/pull/1393))

## Changed

- **core:** Selection endpoints are normalized to whole graphemes. Highlighting, copied text, deletion, cursor sync and wrapped-line navigation now agree in both directions. Extending a selection by one display column no longer splits a wide grapheme. A press without movement keeps the selection empty. A cursor at the end of a line does not select the newline, but crossing the line boundary does. See [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1393](https://github.com/anomalyco/opentui/pull/1393))

## Fixed

- **core:** A selection no longer flips when `x` is left of the text and `y` is below it. See [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1381](https://github.com/anomalyco/opentui/pull/1381))
- **core:** Forced Sixel output is rejected unless the detected host supports Sixel. Apple Terminal and terminal multiplexers now fall back to blocks. See [Terminal capabilities](/docs/reference/terminal-capabilities). ([#1387](https://github.com/anomalyco/opentui/pull/1387))
- **core:** OSC 66 probe responses are matched to their requests. See [Terminal capabilities](/docs/reference/terminal-capabilities). ([#1384](https://github.com/anomalyco/opentui/pull/1384))
- **core:** Split-footer commits on Darwin ARM64 no longer lose frame-finalization state. Native boolean flags are passed as numeric bytes, so Bun and Node share one FFI contract. Cell attributes are tested as `u32` on all platforms under Node. See [Runtime and platform support](/docs/getting-started/runtime-support). ([#1409](https://github.com/anomalyco/opentui/pull/1409), [#1411](https://github.com/anomalyco/opentui/pull/1411))
- **core:** Node.js releases later than 26.4.0 are supported. 26.4.0 remains the minimum. See [Runtime and platform support](/docs/getting-started/runtime-support). ([#1410](https://github.com/anomalyco/opentui/pull/1410))
