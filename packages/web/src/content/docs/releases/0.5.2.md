date: 2026-08-12
summary: Adds a cross-platform clipboard API for the host and the terminal, and lets ImageRenderable accept a NativeImage.
---

## Added

- **core:** `createClipboard()` combines the host clipboard and the terminal clipboard behind one `ClipboardService` with `read()`, `writeText()`, `clear()`, and `dispose()`. `createHostClipboard()` reads and changes the clipboard of the machine that runs the process. `createRendererClipboardAdapter()` writes or clears the terminal user's clipboard with OSC 52. `writeText()` and `clear()` take a `destination` of `"terminal-only"`, `"host-only"`, `"best-available"`, or `"all-available"`. See [Clipboard](/docs/core-concepts/clipboard). ([#1271](https://github.com/anomalyco/opentui/pull/1271))
- **core:** `ImageRenderable` accepts a `NativeImage` as `source` (`ImageRenderableSource`) without decoding it again. `NativeImage.retain()` returns a new handle, so the caller can dispose its own handle at once. `NativeImage.ensureEncodedPng()` encodes the image as PNG on request. See [Image](/docs/components/image) and [NativeImage](/docs/reference/native-image). ([#1356](https://github.com/anomalyco/opentui/pull/1356))

## Changed

- **core:** Unicode 17 data is now used for character width and grapheme handling. ([#1286](https://github.com/anomalyco/opentui/pull/1286))
- **core:** Automatic terminal detection forwards the SSH and mosh markers, so remote sessions do not inherit the capabilities of the host terminal. ([#1286](https://github.com/anomalyco/opentui/pull/1286))
- **native:** `libopentui` now links Ghostty VT statically. Native packages are one self-contained library and include the Ghostty, uucode, and Unicode notices. ([#1317](https://github.com/anomalyco/opentui/pull/1317))

## Fixed

- **core:** `CodeRenderable` no longer creates unbounded Tree-sitter worker work during streaming. It runs one highlight at a time and keeps only the latest pending content. Highlight settlement now includes queued reruns, so rendered output and scrollback match the current content. `CodeRenderable.destroy()` is now exported. See [Code](/docs/components/code). ([#1331](https://github.com/anomalyco/opentui/pull/1331))
- **core:** A failed one-shot Tree-sitter highlight request now rejects instead of staying unresolved. `TreeSitterWorkerResponse` errors carry an optional `messageId`. See [Syntax highlighting with Tree-sitter](/docs/reference/tree-sitter). ([#1331](https://github.com/anomalyco/opentui/pull/1331))
