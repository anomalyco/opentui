## Added

- **core:** `EmbeddedTerminalRenderable` renders terminal output into the layout. Call `write()` to send output to it. It handles focus, key, paste, and mouse input, scrollback, text selection, resize, and the hardware cursor. Options are `cols`, `rows`, `maxScrollback`, `selectable`, `onData`, `onScreenChange`, and `onTerminalResize`. `onData` receives the encoded bytes for your process, and its `source` argument is `"input"` or `"response"`. `screen()` returns the visible text, and `getSelectedText()` returns the selection. The renderable does not start or own a process or PTY. It does not send SGR-pixel mouse reports because OpenTUI uses cell coordinates. See [Embedded terminal](/docs/components/embedded-terminal). ([#1340](https://github.com/anomalyco/opentui/pull/1340))
- **native:** The native library exports the embedded terminal interface. On custom targets that do not support it, the exported functions return an explicit unsupported status. See [Embedded terminal](/docs/components/embedded-terminal). ([#1340](https://github.com/anomalyco/opentui/pull/1340))

## Changed

- **core:** `OptimizedBuffer.drawPackedBuffer()` and `OptimizedBuffer.drawSuperSampleBuffer()` accept a `Uint8Array` as well as a pointer. The parameters are renamed from `dataPtr` to `data` and from `pixelDataPtr` to `pixelData`. See [Buffer API](/docs/reference/buffer-api). ([#1394](https://github.com/anomalyco/opentui/pull/1394))
- **core:** `RenderLib.bufferColorMatrix`, `bufferColorMatrixUniform`, `bufferDrawGrayscaleBuffer`, `bufferDrawGrayscaleBufferSupersampled`, `bufferDrawPackedBuffer`, and `bufferDrawSuperSampleBuffer` accept a typed array as well as a pointer. See [FrameBuffer color matrices](/docs/reference/color-matrix). ([#1394](https://github.com/anomalyco/opentui/pull/1394))

## Fixed

- **core:** Typed arrays passed to native calls on Bun no longer risk a stale native address when the array moves into separate `ArrayBuffer` storage. ([#1394](https://github.com/anomalyco/opentui/pull/1394))
