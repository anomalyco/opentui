## Security

- **solid:** Updates the exact `@babel/core` pin from 7.28.0 to 7.29.7. Version 7.28.0 is affected by GHSA-4x5r-pxfx-6jf8 (CVE-2026-49356). Packages that depend on `@opentui/solid` can now use a fixed version. Transform output is unchanged. See [Solid bindings](/docs/bindings/solid). ([#1573](https://github.com/anomalyco/opentui/pull/1573))
