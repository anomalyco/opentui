## Added

- **core:** `EditBuffer.getTabWidth()` and `EditBuffer.setTabWidth(width)` read and change the tab width. Changing it keeps cursor positions and undo/redo history valid. See [Editing buffers and views](/docs/extend/editing). ([#1449](https://github.com/anomalyco/opentui/pull/1449))
- **native:** Zig consumers can import the audio module from the `opentui` package. See [Audio](/docs/core-concepts/audio). ([#1431](https://github.com/anomalyco/opentui/pull/1431))
- **native:** `opentui.yoga_c` exposes the Yoga C API to Zig consumers. This export is unstable and can change or be removed without notice. See [Yoga API](/docs/reference/yoga). ([#1454](https://github.com/anomalyco/opentui/pull/1454))
- **native:** `OTUI_GHOSTTY_LOG_LEVEL` sets the level of Ghostty log messages that OpenTUI forwards to its logger. It accepts `error` or `err`, `warn` or `warning`, `info`, and `debug`. Without it, or with an invalid value, these messages are discarded. See [Environment variables](/docs/reference/env-vars). ([#1426](https://github.com/anomalyco/opentui/pull/1426))

## Changed

- **core:** Wrapped text layout uses less time and memory. On a 945 KB Unicode fixture, initial layout takes 6.5 ms instead of 11.3 ms. Appending text and measuring the wrapped result is about 5 times faster. OpenTUI now builds word-break metadata during the first wrapped layout, so this costs more memory for views that are never resized. The first resize alone is slightly slower on that fixture. See [Text and terminal cells](/docs/core-concepts/text-and-cells). ([#1428](https://github.com/anomalyco/opentui/pull/1428), [#1456](https://github.com/anomalyco/opentui/pull/1456))
- **core:** Changing the tab width of text that has no tabs is now constant time. On a 1 MiB fixture, 40 changes took 211 ms before. See [Editing buffers and views](/docs/extend/editing). ([#1450](https://github.com/anomalyco/opentui/pull/1450))

## Fixed

- **core:** Wrapped text no longer splits CJK characters and emoji incorrectly or starts wrapped lines with extra whitespace. Graphemes that contain visible characters and whitespace are no longer dropped at wrap boundaries. See [Text and terminal cells](/docs/core-concepts/text-and-cells). ([#1428](https://github.com/anomalyco/opentui/pull/1428), [#1447](https://github.com/anomalyco/opentui/pull/1447))
- **core:** Copying text that the renderer truncated with an ellipsis now copies the full source text. For example, `ABCDE好` at width 4 copied `ABC`. See [Text and terminal cells](/docs/core-concepts/text-and-cells). ([#1448](https://github.com/anomalyco/opentui/pull/1448))
- **core:** Changing the tab width no longer leaves stale cached text metrics or moves cursors in live text and undo/redo history. See [Editing buffers and views](/docs/extend/editing). ([#1428](https://github.com/anomalyco/opentui/pull/1428), [#1449](https://github.com/anomalyco/opentui/pull/1449))
- **core:** Selection in `EmbeddedTerminalRenderable` highlights only the cells that contain text, not trailing cells and empty rows. A drag selects text only after the pointer leaves its starting cell. See [Embedded terminal](/docs/components/embedded-terminal). ([#1451](https://github.com/anomalyco/opentui/pull/1451))
- **core:** Embedded terminals now encode arrow keys, Ctrl+C, and Escape correctly for programs that use the Kitty keyboard protocol. See [Embedded terminal](/docs/components/embedded-terminal). ([#1423](https://github.com/anomalyco/opentui/pull/1423))
- **core:** Hit testing no longer misses the last row and column inside bordered containers, including scrollable, nested, and buffered ones. See [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1441](https://github.com/anomalyco/opentui/pull/1441))
- **core:** A resize signal with unavailable terminal dimensions no longer resets the renderer to 80x24. See [Renderer](/docs/core-concepts/renderer). ([#1440](https://github.com/anomalyco/opentui/pull/1440))
- **core:** A frame delayed by backpressure no longer restarts a continuous render loop that its callback paused or stopped. See [Renderer](/docs/core-concepts/renderer). ([#1170](https://github.com/anomalyco/opentui/pull/1170))
- **core:** The renderer preserves updates to wide graphemes, and the vignette effect preserves grapheme runs. See [Post-processing effects](/docs/extend/post-processing). ([#1424](https://github.com/anomalyco/opentui/pull/1424))
- **native:** Zig standard-library logs, such as those from Ghostty, no longer write to the host terminal and corrupt the display. They are discarded by default. See [Environment variables](/docs/reference/env-vars). ([#1425](https://github.com/anomalyco/opentui/pull/1425))
