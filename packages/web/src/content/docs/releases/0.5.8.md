## Added

- **core:** Adds `"unicode-wide"` to `WidthMethod`. It uses the width profile of Ghostty 1.3, which renders certain multi-code-point graphemes two columns wide, so rendering, wrapping, and cursor placement stay aligned with the terminal. See [Text and terminal cells](/docs/core-concepts/text-and-cells). ([#1415](https://github.com/anomalyco/opentui/pull/1415))

## Fixed

- **core:** Keeps the left-button selection state until the left button is released, so a right-click does not interrupt a drag. See [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1416](https://github.com/anomalyco/opentui/pull/1416))
- **core:** Counts Thai spacing marks, such as SARA AM, in grapheme widths, so output coordinates match the terminal. See [Text and terminal cells](/docs/core-concepts/text-and-cells). ([#1413](https://github.com/anomalyco/opentui/pull/1413))
