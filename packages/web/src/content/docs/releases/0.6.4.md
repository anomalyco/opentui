## Fixed

- **core:** Kitty [images](/docs/components/image) in iTerm2 no longer go black or blank after a move, a scroll, or a layout change. The renderer now deletes each old placement by its placement id, because iTerm2 also frees the image data when it gets an image-wide delete. ([#1662](https://github.com/anomalyco/opentui/pull/1662))
