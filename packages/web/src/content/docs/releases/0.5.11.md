---

## Added

- **core:** `audio.playStream()` accepts `format: "pcm"` with the `sampleFormat`, `sampleRate`, and `channels` options. PCM uses the same stream worker as MP3 and FLAC. Writes go to a bounded 256 KiB input queue and are validated asynchronously. PCM reconnect is not supported. See [Streaming audio](/docs/application-apis/audio-streaming). ([#1481](https://github.com/anomalyco/opentui/pull/1481))
- **core:** `CliRenderer.getLinkAt(x, y)` returns the URL at a cell, and `CliRenderer.getLinkIdAt(x, y)` returns its link ID. See [Renderer](/docs/core-concepts/renderer). ([#1442](https://github.com/anomalyco/opentui/pull/1442))
- **core:** `TextBufferRenderable.getLineSources()` and `CodeRenderable.getLineSources()` return the source IDs of a range of visual lines. `detectLinks()` and `ChunkRenderContext` accept optional `sourceRanges`. See [Code](/docs/components/code). ([#1442](https://github.com/anomalyco/opentui/pull/1442), [#1462](https://github.com/anomalyco/opentui/pull/1462))
- **core:** `CodeRenderable.updateStreamingPreview(content, initialStyledText)` updates streamed code with a styled preview. See [Code](/docs/components/code). ([#1442](https://github.com/anomalyco/opentui/pull/1442))
- **native:** Line wrapping can break between CJK characters. ([#1453](https://github.com/anomalyco/opentui/pull/1453))
- **core:** Bun 1.4 is supported. See [Runtime and platform support](/docs/getting-started/runtime-support). ([#1400](https://github.com/anomalyco/opentui/pull/1400))

## Changed

- **core:** Markdown named links and bare links are clickable in terminals that support OSC 8, and the link destination is not shown. Other terminals show the visible URL. Links stay intact across formatting, streaming, wrapping, and late terminal capability detection. See [Markdown](/docs/components/markdown). ([#1442](https://github.com/anomalyco/opentui/pull/1442))
- **core:** Large diffs paint and highlight only the rows that reach the screen. Applying syntax highlights to 5,000 JSON fields takes 164 ms instead of 5,973 ms. See [Diff](/docs/components/diff). ([#1462](https://github.com/anomalyco/opentui/pull/1462))

## Removed

- **core:** `DiffRenderable.onResize()` is no longer a protected method. Diff alignment rebuilds when the width of a pane changes. Subclasses that override or call `onResize()` must use another resize hook. See [Diff](/docs/components/diff). ([#1463](https://github.com/anomalyco/opentui/pull/1463))

## Fixed

- **core:** `EmbeddedTerminalRenderable` keeps the active-layout key when it encodes Kitty keyboard input. With a Dvorak layout, Ctrl+U and Ctrl+D no longer reach the child process as Ctrl+F and Ctrl+H. See [Embedded terminal](/docs/components/embedded-terminal). ([#1477](https://github.com/anomalyco/opentui/pull/1477))
- **core:** Split diffs realign after the viewer changes between split and unified views or is resized. Scrolling to the end no longer shows blank rows in place of the removed and added line tails. See [Diff](/docs/components/diff). ([#1463](https://github.com/anomalyco/opentui/pull/1463))
