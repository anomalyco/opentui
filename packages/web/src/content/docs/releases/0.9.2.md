## Fixed

- **native:** If the native library is missing outside an OpenTUI checkout, the `opentui-sys` build script names the release archive to extract, such as `opentui-native-v0.9.2-linux-x64.zip`, instead of `bun run build`. Set `OPENTUI_LIB_HINT` to replace this advice with your own setup step. See [Rust](/docs/bindings/rust). ([#2150](https://github.com/anomalyco/opentui/pull/2150))
