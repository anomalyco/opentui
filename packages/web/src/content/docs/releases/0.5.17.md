## Added

- **native:** Hyperlink detection enables OSC 8 in more terminals: xterm.js (detected with XTVERSION), `TERM_PROGRAM` values `vscode`, `zed`, and `mintty`, and VTE 0.52.2 or newer. Without OSC 8, the terminal detects URLs one row at a time, so a wrapped link opens only the part on the clicked row. `TERM_PROGRAM` and `VTE_VERSION` count only outside a multiplexer, and detection revokes them if OpenTUI detects a multiplexer later. `FORCE_HYPERLINK` overrides detection, and the values `0`, `false`, and `off` disable hyperlinks. See [Terminal capabilities](/docs/reference/terminal-capabilities). ([#1575](https://github.com/anomalyco/opentui/pull/1575))
