summary: Fixes a text buffer memory leak, a layout rerender loop, and tmux capability replies reaching the wrong pane.
---

## Changed

- **core:** Drawing text and box titles, resizing buffers, blending colors, and updating `TextTable` selections now use less CPU. ([#1538](https://github.com/anomalyco/opentui/pull/1538), [#1539](https://github.com/anomalyco/opentui/pull/1539)) See [Buffer API](/docs/reference/buffer-api).
- **native:** Color rounding no longer calls `roundf`, and buffer resizes reuse the existing cell arrays while the new size fits. A failed resize leaves the buffer unchanged. See [Buffer API](/docs/reference/buffer-api). ([#1536](https://github.com/anomalyco/opentui/pull/1536), [#1537](https://github.com/anomalyco/opentui/pull/1537))

## Fixed

- **core:** Renderables attached after a layout pass keep their prior size until Yoga reports valid dimensions. This stops continuous rerenders and high CPU use. See [Layout](/docs/core-concepts/layout). ([#1545](https://github.com/anomalyco/opentui/pull/1545))
- **native:** Replacing text in a text buffer or edit buffer no longer keeps the previous document in memory. See [Editing buffers and views](/docs/extend/editing). ([#1544](https://github.com/anomalyco/opentui/pull/1544))
- **core:** Under tmux, capability queries stay inside tmux and replies go to the pane that asked. OpenTUI no longer sends the Kitty graphics query under tmux and ignores unowned Kitty graphics replies. An explicit image protocol override still works. See [Terminal capabilities](/docs/reference/terminal-capabilities). ([#1460](https://github.com/anomalyco/opentui/pull/1460))
- **core:** Destroying a portal now destroys its children, so their listeners no longer leak. See [Lifecycle and cleanup](/docs/core-concepts/lifecycle). ([#1522](https://github.com/anomalyco/opentui/pull/1522))
- **core:** Kitty images with a z-index above the cell background now render in the correct order. See [Image](/docs/components/image). ([#1525](https://github.com/anomalyco/opentui/pull/1525))
- **ssh:** Accepted connections disable Nagle's algorithm. On Node, this removes a delay of about 40 ms on each reply. See [SSH](/docs/reference/ssh). ([#1531](https://github.com/anomalyco/opentui/pull/1531))
