summary: Sideways wheel steps no longer shift truncated text with `wrapMode` set to `"none"` by one column.
---

## Fixed

- **core:** A left or right wheel step no longer shifts a [`Text`](/docs/components/text) or [`Code`](/docs/components/code) with `wrapMode: "none"` and `truncate: true` by one column. A text with a sideways offset now returns to column 0 when `truncate` becomes `true` or `wrapMode` changes to `"word"` or `"char"`. ([#1745](https://github.com/anomalyco/opentui/pull/1745))
