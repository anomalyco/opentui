date: 2026-09-01
summary: Kitty image streaming uses less CPU, and native libraries now ship stripped with separate debug symbols.

## Added

- **core:** `NativeImage.fromPixels(pixels, width, height, options?)` creates an image from raw pixels. `PixelImportOptions` sets `format`, `stride`, `alpha`, and `colorSpace`. See [NativeImage](/docs/reference/native-image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
- **core:** `NativeImagePool` reuses native image buffers for frames of a fixed size. Use `publishPixels()` or `publishRgba()` to publish a frame and `dispose()` to release the pool. See [NativeImage](/docs/reference/native-image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
- **core:** `CliRendererConfig.kittyImageTransport` and `renderer.kittyImageTransport` select the Kitty image transport: `"raw"`, `"zlib"`, or `"file"`. Raw is the default. File transport is opt-in and is used only on terminals that acknowledge image uploads. See [Image](/docs/components/image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
- **core:** `renderer.kittyImageTransportStatus` reports the requested and effective transport, the file transport state, the fallback reason, and the pending bytes and files. `renderer.cancelKittyImageTransport()` cancels pending file transport. See [Image](/docs/components/image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
- **native:** Release builds now publish `.debug`, `.dSYM`, and `.pdb` symbol files as separate GitHub Release assets. See [Native crash debugging](/docs/test-and-debug/native-crashes). ([#1437](https://github.com/anomalyco/opentui/pull/1437))

## Changed

- **core:** Image streaming uses less CPU for frame preparation and transport. Pending frames are bounded when terminal output stalls. See [Image](/docs/components/image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
- **core:** The renderer shows Kitty and Sixel images in scrollback before the footer is pinned, if the images fit above the pinned footer. They no longer fall back to blocks during startup and after a resize. See [Renderer](/docs/core-concepts/renderer). ([#1470](https://github.com/anomalyco/opentui/pull/1470))
- **core:** `ImageErrorCode` includes `"busy"`. See [NativeImage](/docs/reference/native-image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
- **native:** The npm packages ship stripped native libraries. The Linux library shrinks from about 26 MB to about 6 MB. Debug builds are unchanged. See [Native crash debugging](/docs/test-and-debug/native-crashes). ([#1437](https://github.com/anomalyco/opentui/pull/1437))

## Fixed

- **core:** `MarkdownRenderable` keeps its response visible when `streaming` changes from `true` to `false`. Compatible top-level blocks are refreshed in place, not destroyed and recreated. See [Markdown](/docs/components/markdown). ([#1469](https://github.com/anomalyco/opentui/pull/1469))
- **core:** The renderer retries the final automatic animation frame when threaded output rejects it under backpressure. Before, the previous frame stayed on screen. See [Renderer](/docs/core-concepts/renderer). ([#1457](https://github.com/anomalyco/opentui/pull/1457))
- **core:** Image rendering no longer grows GPU resources on every frame or retains native handles during sustained rendering. See [Image](/docs/components/image). ([#1467](https://github.com/anomalyco/opentui/pull/1467))
