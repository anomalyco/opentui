## Added

- **core:** `createTextAttributes()` accepts a `reverse` option. See [Text and terminal cells](/docs/core-concepts/text-and-cells).

## Fixed

- **core:** Clipboard copies with OSC 52 now work in GNU Screen, including large values. The renderer no longer leaves an unterminated OSC 52 request in the outer terminal. See [Clipboard](/docs/core-concepts/clipboard). ([#1334](https://github.com/anomalyco/opentui/pull/1334))
- **core:** The renderer clears pending terminal input on shutdown. The next application no longer reads stale mouse reports as escape sequences. Input received after `suspend()` is kept. See [Lifecycle and cleanup](/docs/core-concepts/lifecycle). ([#1382](https://github.com/anomalyco/opentui/pull/1382))
- **core:** A forced Sixel placement, either a `"sixel"` placement or `OPENTUI_IMAGE_PROTOCOL=sixel`, now uses the blocks fallback on Kitty. Kitty does not implement Sixel, and large payloads were printed on the screen as text. See [Image](/docs/components/image). ([#1378](https://github.com/anomalyco/opentui/pull/1378))
