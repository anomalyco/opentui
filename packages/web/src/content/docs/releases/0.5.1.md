## Added

- **core:** PNG images with an embedded ICC profile are now validated and converted to sRGB when their pixels are decoded. PNGs that qualify stay encoded for direct Kitty passthrough, and pixels are decoded only when needed. See [NativeImage](/docs/reference/native-image). ([#1327](https://github.com/anomalyco/opentui/pull/1327))

## Fixed

- **core:** PNG images with ASCII space, tab, LF, or CR bytes after the `IEND` chunk now load. Malformed chunks and other trailing data are still rejected. See [NativeImage](/docs/reference/native-image). ([#1326](https://github.com/anomalyco/opentui/pull/1326))
