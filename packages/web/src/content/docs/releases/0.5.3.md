## Fixed

- **core:** Fixes an abort when a width-1 glyph is drawn at column -1. The renderer now clips a glyph whose range ends at or before column 0, and it no longer reads past the cell buffer. See [Text](/docs/components/text). ([#1361](https://github.com/anomalyco/opentui/pull/1361))
