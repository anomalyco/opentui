date: 2026-10-07
summary: Adds a `preserve` option to runtime plugin support so host-provided modules keep their bare specifiers.

## Breaking changes

- **core:** `DiffRenderable.destroyRecursively()` is removed. Call `destroy()` instead. `DiffRenderable` now frees its internal views in the protected `destroySelf()` method. See [Lifecycle and cleanup](/docs/core-concepts/lifecycle). ([8ec0082](https://github.com/anomalyco/opentui/commit/8ec008230))

## Added

- **core:** `CreateRuntimePluginOptions.preserve` takes a list or set of specifiers, or a predicate. The runtime plugin leaves matching bare specifiers unchanged, so a module that the host registers with `build.module()` is not replaced by a copy from `node_modules`. `core` and `additional` modules still take precedence. See [Load plugins and modules at runtime](/docs/extend/runtime-plugins). ([#1569](https://github.com/anomalyco/opentui/pull/1569))
- **react:** `ReactRuntimePluginSupportOptions.preserve` accepts the same values. See [Load plugins and modules at runtime](/docs/extend/runtime-plugins). ([#1569](https://github.com/anomalyco/opentui/pull/1569))
- **solid:** `SolidRuntimePluginSupportOptions.preserve` accepts the same values. See [Load plugins and modules at runtime](/docs/extend/runtime-plugins). ([#1569](https://github.com/anomalyco/opentui/pull/1569))

## Fixed

- **core:** `drawBox` and `drawPackedBuffer` draw nothing when the width or height is zero or negative. Before, a negative extent reached native code as a very large value and could crash it, and a zero packed-buffer width divided by zero. `pushScissorRect` clips to an empty rectangle for such extents, so the matching pop stays balanced. See [Buffer API](/docs/reference/buffer-api). ([#1559](https://github.com/anomalyco/opentui/pull/1559))
- **native:** Blended cell writes reject negative coordinates. Before, an off-screen write could overflow or address an invalid cell. See [Buffer API](/docs/reference/buffer-api). ([#1556](https://github.com/anomalyco/opentui/pull/1556))
- **core:** `DiffRenderable` and `LineNumberRenderable` free their cached internal views when you destroy them. `LineNumberRenderable` now has its own `destroy()` method. See [Lifecycle and cleanup](/docs/core-concepts/lifecycle). ([8ec0082](https://github.com/anomalyco/opentui/commit/8ec008230))
- **solid:** Slot placeholders are freed when their slot child is destroyed. See [Solid plugin slots](/docs/plugins/solid). ([8ec0082](https://github.com/anomalyco/opentui/commit/8ec008230))
