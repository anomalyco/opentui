---
date: 2026-09-22
summary: Adds `textAlign` for text renderables and more mouse pointer styles, and fixes several rendering and cleanup issues.
---

## Added

- **core:** `textAlign` aligns each line of a text renderable to `"left"`, `"center"`, or `"right"`. It works with `wrapMode` set to `"char"` or `"word"`. Alignment applies after wrapping. `TextBufferView.setTextAlign()` sets it on a view. See [Text](/docs/components/text). ([#1507](https://github.com/anomalyco/opentui/pull/1507))
- **core:** `MousePointerStyle` accepts the full set of CSS cursor names, such as `"grab"`, `"wait"`, `"help"`, and `"col-resize"`. Terminals differ in which OSC 22 pointer styles they support. See [Interaction, focus, and selection](/docs/core-concepts/interaction). ([#1037](https://github.com/anomalyco/opentui/pull/1037))
- **core:** `EmbeddedTerminalRenderable` has a `transparentBackground` option, `false` by default. When it is `true`, cells with no explicit background use the host terminal background. Cells with an explicit background stay opaque. You can change it after creation. See [Embedded terminal](/docs/components/embedded-terminal). ([#1502](https://github.com/anomalyco/opentui/pull/1502))
- **core:** `EditorView.isDestroyed` reports whether the view has been destroyed. See [Editing buffers and views](/docs/extend/editing). ([#1504](https://github.com/anomalyco/opentui/pull/1504))
- **core:** `TextTableRenderable` has an `fg` property that sets the text color of existing cells. See [TextTable](/docs/components/text-table). ([#1503](https://github.com/anomalyco/opentui/pull/1503))

## Fixed

- **core:** `MarkdownRenderable` passes its `fg` to tables. Table text no longer always uses the `#FFFFFF` default, and a later change to `fg` recolors existing tables. See [Markdown](/docs/components/markdown). ([#1503](https://github.com/anomalyco/opentui/pull/1503))
- **core:** Reading the cursor of a destroyed editor returns an empty cursor. Listeners that run during destruction no longer throw. See [Editing buffers and views](/docs/extend/editing). ([#1504](https://github.com/anomalyco/opentui/pull/1504))
- **core:** Shrinking the width of a split footer no longer leaves stale rows on screen. Cleanup now starts at the visible footer origin. See [Renderer](/docs/core-concepts/renderer). ([#1488](https://github.com/anomalyco/opentui/pull/1488))
- **core:** A scrollback snapshot that starts in the middle of a line stays aligned with the text already written before it. Rendering and hit testing now use the same cells. See [Text and terminal cells](/docs/core-concepts/text-and-cells). ([#1511](https://github.com/anomalyco/opentui/pull/1511))
- **core:** A worker error that arrives while the worker is terminating no longer becomes an uncaught exception in Node. See [Lifecycle and cleanup](/docs/core-concepts/lifecycle). ([#1508](https://github.com/anomalyco/opentui/pull/1508))
