## Fixed

- **native:** Programs on x64 Windows that link the static library with the static MSVC C runtime and also call `strtod` now link without the `LNK2005` error for `strtold`. The library keeps its bundled MinGW runtime copies private, and MinGW programs that call `strtold` still work. See [Rust](/docs/bindings/rust). ([#2157](https://github.com/anomalyco/opentui/pull/2157))
