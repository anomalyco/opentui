summary: The Rust crates are published as opentui and opentui-sys again, in place of anomalyco-opentui and anomalyco-opentui-sys.
---

A Rust app on version 0.9.5 of the crates has this dependency in its `Cargo.toml`:

```toml
[dependencies]
opentui = { package = "anomalyco-opentui", version = "0.9.5" }
```

There is no 0.9.6 of that package. On crates.io, an unrelated project held the names `opentui` and `opentui-sys`, so 0.9.4 and 0.9.5 went out as `anomalyco-opentui` and `anomalyco-opentui-sys`. OpenTUI now owns the real names. This release and later ones use them, and the interim names stop at 0.9.5. To upgrade, remove the `package` key:

```toml
[dependencies]
opentui = "0.9.6"
```

Cargo commands change the same way. `cargo test -p anomalyco-opentui` becomes `cargo test -p opentui`, and `--features anomalyco-opentui/tokio` becomes `--features opentui/tokio`. The library was always named `opentui`, so no `use` line changes. `opentui-ssh` also kept its name. A Git dependency on tag v0.9.4 or v0.9.5 still needs `package = "anomalyco-opentui"`, because the crates at those tags have that name. As before, use the native archive from the same release as the crates, such as `opentui-native-v0.9.6-linux-x64.zip`. See [Install, link, and ship](/docs/bindings/rust/install).

## Breaking changes

- **native:** The Rust crates are published as `opentui` and `opentui-sys` again, and `anomalyco-opentui` and `anomalyco-opentui-sys` stop at 0.9.5. Replace `opentui = { package = "anomalyco-opentui", ... }` with `opentui = "0.9.6"`, and use `opentui` and `opentui-sys` with `cargo -p` and `--features`. See [Install, link, and ship](/docs/bindings/rust/install). ([#2179](https://github.com/anomalyco/opentui/pull/2179))

## Fixed

- **native:** With math on, Core and Rust Markdown now draw a `$` before a held pipe, as in `$|$[`, as plain text while the line waits to become a table header. Before, that `$` used the math style. See [Markdown](/docs/components/markdown) and [Code, Markdown, and highlighting](/docs/bindings/rust/text). ([#2178](https://github.com/anomalyco/opentui/pull/2178))
- **native:** With a syntax theme, Rust `Markdown` now draws prose in its text color with the background and attributes of the `default` scope, also in quotes, as Core does. Before, prose used the foreground of the `default` scope and not its background. See [Code, Markdown, and highlighting](/docs/bindings/rust/text). ([#2177](https://github.com/anomalyco/opentui/pull/2177))
