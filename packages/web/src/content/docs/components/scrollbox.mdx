# ScrollBox

`ScrollBox` scrolls arbitrary child renderables. Its scroll position, sticky edge, and scrollbars are native state of its own scene node, so scrolling and following new content need no layout pass and no host round trip. Use a standalone [ScrollBar](/docs/components/scrollbar) only when another model owns the scroll position.

## Availability

| Field           | Availability              |
| --------------- | ------------------------- |
| Package         | `@opentui/core`           |
| Core renderable | `ScrollBoxRenderable`     |
| React           | `<scrollbox>` (automatic) |
| Solid           | `<scrollbox>` (automatic) |
| Status          | Built in                  |

## Basic usage

### Renderable API

```typescript
import { ScrollBoxRenderable, TextRenderable, BoxRenderable, createCliRenderer } from "@opentui/core"

const renderer = await createCliRenderer()

const scrollbox = new ScrollBoxRenderable(renderer, {
  id: "scrollbox",
  width: 40,
  height: 20,
})

// Add content to the scrollbox
for (let i = 0; i < 100; i++) {
  scrollbox.add(
    new BoxRenderable(renderer, {
      id: `item-${i}`,
      width: "100%",
      height: 2,
      backgroundColor: i % 2 === 0 ? "#292e42" : "#2f3449",
    }),
  )
}

renderer.root.add(scrollbox)
```


## Sticky scroll

Enable sticky scroll to keep content pinned to an edge as new content arrives. Set both `stickyScroll` and `stickyStart` because `stickyStart` has no default.

```typescript
const scrollbox = new ScrollBoxRenderable(renderer, {
  id: "logs",
  width: 60,
  height: 20,
  stickyScroll: true,
  stickyStart: "bottom", // New content will keep the view scrolled to bottom
})
```

### Sticky positions

- `"bottom"`: Stay scrolled to the bottom
- `"top"`: Stay scrolled to the top
- `"left"`: Stay scrolled to the left
- `"right"`: Stay scrolled to the right

When you scroll away from the sticky position, sticky behavior pauses until you scroll back to the sticky edge.

## Bidirectional scrolling

Enable scrolling in both directions:

```typescript
const scrollbox = new ScrollBoxRenderable(renderer, {
  id: "canvas",
  width: 60,
  height: 30,
  scrollX: true,
  scrollY: true,
})
```

By default, `scrollY` is `true` and `scrollX` is `false`.

## Viewport culling

Viewport culling skips children outside the viewport in large content. It is on by default:

```typescript
const scrollbox = new ScrollBoxRenderable(renderer, {
  id: "large-list",
  width: 40,
  height: 20,
  viewportCulling: true, // Only render visible items
})
```

Culling applies when the content holds 16 or more direct children, including hidden ones, or when the viewport has zero width or height. Native code then skips each direct child that does not overlap the viewport, with its whole subtree. Otherwise, native code paints all children and clips them to the viewport.

Skipped children and their descendants run no paint hooks (`renderBefore`, `renderSelf`, and `renderAfter`) and no update hook (`onUpdate`). Yoga still computes their layout. A skipped direct child still runs its resize hook (`onResize`), but its descendants do not. Do not make layout or state depend on paint or update hooks. Disable `viewportCulling` if every child must run these hooks.

## Customizing scrollbars

Style the scrollbars using nested options:

```typescript
const scrollbox = new ScrollBoxRenderable(renderer, {
  id: "styled-scroll",
  width: 40,
  height: 20,
  scrollbarOptions: {
    showArrows: true,
    trackOptions: {
      foregroundColor: "#7aa2f7",
      backgroundColor: "#414868",
    },
  },
  // Or customize vertical and horizontal separately
  verticalScrollbarOptions: {
    trackOptions: { backgroundColor: "#333" },
  },
  horizontalScrollbarOptions: {
    trackOptions: { backgroundColor: "#333" },
  },
})
```

## Customizing sub-components

The wrapper, viewport, and content areas take a background color each. The viewport also takes padding in whole cells, and the content takes the Yoga layout properties of a box (direction, alignment, padding, gap, sizes). Other box options of these parts are ignored:

```typescript
const scrollbox = new ScrollBoxRenderable(renderer, {
  id: "custom-scroll",
  width: 40,
  height: 20,
  rootOptions: {
    backgroundColor: "#24283b",
  },
  wrapperOptions: {
    backgroundColor: "#1f2335",
  },
  viewportOptions: {
    backgroundColor: "#1a1b26",
  },
  contentOptions: {
    backgroundColor: "#16161e",
  },
})
```

## Scroll methods

### scrollBy

Scroll by a relative amount:

```typescript
// Scroll down 5 lines
scrollbox.scrollBy(5)

// Scroll with both x and y
scrollbox.scrollBy({ x: 10, y: 5 })

// Scroll by viewport (page)
scrollbox.scrollBy(1, "viewport")
```

`scrollBy` and `scrollTo` scroll at once against the current layout and apply again after the next frame's layout, so
a scroll made in the same tick as a content change lands against the new content. A delta adds to a target that is
still waiting for that layout.

### scrollTo

Scroll to an absolute position:

```typescript
// Scroll to top
scrollbox.scrollTo(0)

// Scroll to specific position
scrollbox.scrollTo({ x: 0, y: 100 })
```

A position at or past the end, such as `scrollTo(scrollbox.scrollHeight)` or `scrollTo(Infinity)`, stays at the end
after the content grows. `NaN` throws a `RangeError`.

The same list after `scrollTo(5)`:


### scrollChildIntoView

Scroll the minimum distance needed to show a nested child in the viewport. The method uses DOM-style "nearest"
behavior. If the child already fits, the call is a no-op. An oversized child also stays in place when it extends beyond
both edges of an axis. Otherwise, the method scrolls to reveal the nearest edge.

```typescript
scrollbox.scrollChildIntoView("table-row-42")
```

Use it when you focus an offscreen element, such as a search result or a new form field. Pass the renderable instead of
an id, and an `align` of `"start"` or `"end"` to put that edge of the child at the viewport's edge, `inset` cells inside:

```typescript
scrollbox.scrollChildIntoView(message, { align: "start", inset: 1 })
```

Like `scrollTo`, the call applies again after the next frame's layout, so a child that moves in that frame still ends
up in view.

### anchor

Keep a child at its place in the viewport while content above it changes, for example while older messages load above
the reader. The anchor holds through every layout until you release it, scroll to the end, or the child leaves the
ScrollBox. It takes precedence over sticky scrolling; a scroll moves the place it keeps. Release takes effect at once,
so release it in `afterLayout`: the frame that lays out the new messages still holds the place.

```typescript
const release = scrollbox.anchor(firstVisibleRow)
await loadOlderMessages()
scrollbox.afterLayout(release)
```

### afterLayout

Run a callback once in the next frame, after its layout and before it paints. Layout reads in the callback are current,
and a scroll it makes shows in that frame, so no frame shows the content at the old position.

```typescript
scrollbox.afterLayout(() => scrollbox.scrollChildIntoView(newRow, { align: "end" }))
```

The callback waits while the ScrollBox is hidden. Destroying the ScrollBox drops it.

## Keyboard navigation

When focused, ScrollBox responds to keyboard input:

- **Arrow keys:** Move by one fifth of the active viewport.
- **Page Up/Down:** Move by one half of the vertical viewport.
- **Home/End:** Move to the start or end.

## Properties

| Property                     | Type                                     | Default | Description                            |
| ---------------------------- | ---------------------------------------- | ------- | -------------------------------------- |
| `scrollX`                    | `boolean`                                | `false` | Enable horizontal scrolling            |
| `scrollY`                    | `boolean`                                | `true`  | Enable vertical scrolling              |
| `stickyScroll`               | `boolean`                                | `false` | Keep scroll position pinned to an edge |
| `stickyStart`                | `"top" \| "bottom" \| "left" \| "right"` | -       | Which edge to stick to                 |
| `viewportCulling`            | `boolean`                                | `true`  | Skip children outside the viewport     |
| `scrollAcceleration`         | `ScrollAcceleration`                     | -       | Custom scroll acceleration algorithm   |
| `rootOptions`                | `BoxOptions`                             | -       | Style options for root container       |
| `wrapperOptions`             | `BoxOptions`                             | -       | Style options for wrapper              |
| `viewportOptions`            | `BoxOptions`                             | -       | Style options for viewport             |
| `contentOptions`             | `BoxOptions`                             | -       | Style options for content container    |
| `scrollbarOptions`           | `ScrollBarOptions`                       | -       | Options for both scrollbars            |
| `verticalScrollbarOptions`   | `ScrollBarOptions`                       | -       | Options for vertical scrollbar only    |
| `horizontalScrollbarOptions` | `ScrollBarOptions`                       | -       | Options for horizontal scrollbar only  |

## Additional properties

| Property       | Type     | Description                                  |
| -------------- | -------- | -------------------------------------------- |
| `scrollTop`    | `number` | Current vertical scroll position (get/set)   |
| `scrollLeft`   | `number` | Current horizontal scroll position (get/set) |
| `scrollWidth`  | `number` | Total scrollable width (read-only)           |
| `scrollHeight` | `number` | Total scrollable height (read-only)          |

## Parts

ScrollBox exposes its parts for geometry, events, and styling. They are views of the ScrollBox's native state, not renderables: they have no children of their own and cannot be added to another node.

```typescript
scrollbox.wrapper // x, y, width, height, backgroundColor
scrollbox.viewport // geometry, padding, backgroundColor, "resize" and onSizeChange
scrollbox.content // geometry, layout properties, backgroundColor, "resize" and onSizeChange; add() adds to the ScrollBox
scrollbox.horizontalScrollBar // scrollPosition, scrollBy(), visible, showArrows, trackOptions, "change" and onChange
scrollbox.verticalScrollBar
```

The part classes `ScrollBoxWrapper`, `ScrollBoxViewport`, `ScrollBoxContent`, and `ScrollBoxBar` are exported for type annotations. Children of a ScrollBox report the ScrollBox as their `parent`. A press on a scrollbar or one of its arrows targets the ScrollBox.
